# Pia downloads

Pia 的公开下载清单与应用发行附件。

- 官网：[pia.yoloful.app](https://pia.yoloful.app/)
- 下载清单：[downloads.v1.json](https://gaobais.github.io/pia-releases/downloads.v1.json)
- 安装包：[Releases](https://github.com/GaoBais/pia-releases/releases)

清单中的 `null` 表示该平台暂未提供下载。可用版本发布后，官网会读取更新后的清单，无需重新发布官网。

每个版本使用固定版本号与不可变附件，并提供 SHA-256 校验和。Windows 初期提供未签名安装包，系统可能显示 SmartScreen 或“未知发布者”提示；请确认来源并核对校验和。iOS 使用官方 App Store 或 TestFlight 渠道。

此仓库仅用于分发，不包含用户数据或签名密钥。
